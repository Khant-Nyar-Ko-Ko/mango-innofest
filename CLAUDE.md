# mango-innofest: Mango Bot (บอทมะม่วง) booth website

## What this is
A kid-friendly website for our university project show (Innofest) at a primary school. Our project is an AI **mango** bruise detection system (team IATE, School of Agro-Industry, Mae Fah Luang University). The real system takes a photo of a mango on a plain background, removes the background, marks bruised areas orange and healthy areas green, gives fruit area / bruise area (cm²) / bruise %, and predicts the damage type: pendulum impact ("bumped") or transport vibration ("shaken"). The site explains it to kids aged about 6–12 and has two games. Mascot: a cartoon helper robot called "บอทมะม่วง" (TH) / "Mango Bot" (EN). It is NOT part of the real project and is not a doctor: the site must say it is just a cartoon helper and that the real project is a research website ("Fruit Bruising Detection") used by the School of Agro-Industry, Mae Fah Luang University. That website is for MFU research only: NEVER link to it or show its address on this kids' site. Things the system does are done by "our website / the computer", not by Mango Bot. The site is about bruises on MANGOES, not on people.

## Files
- index.html: landing page. Hero about our website with Mango Bot saying hi, the project in 3 cards (problem: mangoes bruise easily / our idea: camera + AI paints bruise orange, healthy green, gives bruise % / who it helps: researchers, farmers, fruit sellers), a line saying the real system is used for research at the School of Agro-Industry, MFU (no link), 3 big links to the activities, safety notes.
- learn.html: what a mango bruise is (cut-mango diagram: skin, flesh, seed, brown bruised flesh), bruise-darkening slider (day 0–7: hard to see → light brown → brown → dark brown; mangoes can't heal), how our website works (the 6 real steps: upload → tidy up (resize/crop) → remove background → find the bruise (orange/green, %) → look closely (bump or shake) → save results; cat analogy with mango colours, plus the "white table = bumped, grey table = shaken" background mistake from our real training data), "You vs Mango Bot" quiz at learn.html#game (8 cartoon mango cards: brown / bump / shake bruises vs shadow, dirt, natural dots, unripe green, marker ink; Mango Bot (answering like the computer) gets the shadow and marker ink wrong ON PURPOSE to teach that AI makes mistakes), tips to keep mangoes from bruising.
- mango.html: canvas mango catch game. Good mango +1, bruised mango −1, score never below 0, 30 s rounds that speed up, target 15 points = prize (we only have about 20 pens, so the target is set high: a 30 s round drops about 25 catchable good mangoes, range 17–34). If you change the default target, also change the "Get 15 points" text on index.html. Full screen is automatic (no button): tapping Start or Play again puts the HUD + stage in browser full screen (browsers only allow it after a tap, so it cannot start on page load). Staff exit with Esc; the end screen has a "← Back to home" link (falls back to filling the window where the Fullscreen API is blocked, e.g. iPhone Safari). In full screen the stage fills all space under the HUD (capped at 4:3 on wide screens); the game world is always 600 units tall and its width W follows the stage shape (800 at 4:3, narrower on upright phones/tablets), so drawing and spawning must use W, never a fixed 800. Upright phones also get a 3:4 stage before Start so the start card fits. Sounds are made in code with Web Audio (no audio files, works offline): "pop" on a good catch, "bonk" on a bruised one, a cheer on winning; a "🔊 เสียง: เปิด / Sound: on" mute button sits in the stage corner (also visible in full screen) and is remembered in localStorage key "mango-sound". A good catch squash-bounces the basket, a bruised one wobbles it (no wobble with reduced motion). There is NO Team settings panel (removed on request): target (cfg.target=15), round time (cfg.time=30), speed (SPEED=1.15) and bruised share (BAD=.35) are constants in the script; the page clears the old localStorage key "mango-cfg".
- assets/: Mango Bot logo. icon.svg is the tab icon (also the source drawing); favicon-32.png, apple-touch-icon.png (180), icon-192/512.png (full-bleed versions for home screens), og-image.png (1200x630 share preview for LINE/Facebook). PNGs were made from SVG with rsvg-convert, og-image with headless Chrome; redraw them if the mascot changes.
- sitemap.xml, robots.txt, site.webmanifest (home-screen app, display "fullscreen"): use the live URL https://mango-innofest.vercel.app. Every page head has description, canonical, icon, manifest and og:/twitter: tags; a new page needs the same tags and a sitemap entry (update lastmod when pages change).

## Tech rules
- Plain HTML/CSS/JS, one self-contained file per page, no build step, no frameworks. Keep it that way.
- Fonts: "Itim" (display) and "Mali" (body), with Thai system font fallbacks. They are copied into assets/fonts/ (Thai + Latin woff2, fonts.css, OFL licence files) so the site works offline. Do NOT link Google Fonts or any other online resource: the booth must work with no internet.
- Offline: sw.js (service worker, registered at the end of every page) saves every file in its FILES list on first visit, then serves saved copies and refreshes them in the background. When you add or rename a file a page needs, add it to FILES and bump VERSION in sw.js.
- Bilingual Thai/English: a ไทย | EN toggle in every header. Language is saved in localStorage key "drbot-lang", shared across pages. Static text uses data-i18n (index/learn) or data-k (mango) attributes with an EN dictionary in the page script; Thai is the default and lives in the HTML. Any new text MUST get both Thai and English.
- Design: "sticker-book" style (3px navy outlines, offset hard shadows, rounded corners), colours as CSS tokens on :root with a dark-mode version. Keep big touch targets for small hands, and make it work on tablets and phones.
- Content rules: cartoon drawings only. Keep the "Mango Bot is just a cartoon; the real project is the website; computers can make mistakes so people check" and "be gentle with mangoes" messages. Facts about the system must match the research website (iate-fruitbruise.com, for reference only, never linked) and the user manual (~/Downloads/Mango_Bruise_Detection_System__User_Manual.pdf). Simple words a 7-year-old understands.
- Each page has a "← หน้าแรก / ← Home" link back to index.html.
